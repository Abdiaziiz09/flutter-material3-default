# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and the project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-18

### Added

- Material 3 theme foundation with light and dark colour schemes generated
  from a single seed colour.
- Window size class system based on the Material 3 adaptive breakpoints.
- Adaptive navigation shell: navigation bar, navigation rail and extended
  navigation rail depending on the available width.
- Reusable responsive widgets: content container and responsive sliver grid.
- Sample features: home, component showcase and settings.
- AI agent instruction files: `AGENTS.md`, `CLAUDE.md`, Cursor rules and
  GitHub Copilot instructions.
- Standards documentation in `docs/`.
- Strict lint configuration, unit and widget tests, and a GitHub Actions
  workflow.
