# Flutter Material 3 Default

A professional, reusable **Flutter Material 3 foundation** for building mobile,
web and desktop applications — and the standard reference for **AI coding
agents**.

[![CI](https://github.com/Abdiaziiz09/flutter-material3-default/actions/workflows/ci.yml/badge.svg)](https://github.com/Abdiaziiz09/flutter-material3-default/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## Why this repository exists

AI coding agents produce better, more consistent Flutter apps when they start
from a clear standard. Give an agent this repository and it will find:

- instructions it reads automatically (`AGENTS.md`, `CLAUDE.md`, Cursor rules,
  Copilot instructions) requiring **Material 3**, **full responsiveness** and
  **professional code quality** in everything it builds;
- a working foundation (theme, breakpoints, adaptive navigation, reusable
  widgets) to extend rather than reinvent;
- strict lint rules and tests that turn the standard into something verifiable.

## Getting started

Prerequisites: the [Flutter SDK](https://docs.flutter.dev/get-started/install)
(stable channel, 3.32 or newer) with the toolchains for the platforms you
target.

The repository contains the Dart source, configuration and documentation. The
native platform folders (`android/`, `ios/`, `web/`, `windows/`, `macos/`,
`linux/`) are generated by Flutter so they always match your installed SDK.
Run the bootstrap script once after cloning:

```bash
# macOS / Linux
./tool/bootstrap.sh com.yourcompany

# Windows (PowerShell)
.\tool\bootstrap.ps1 -Organization com.yourcompany
```

The script runs `flutter create`, `flutter pub get`, `dart format`,
`flutter analyze` and `flutter test`. Afterwards run the app:

```bash
flutter run -d chrome     # Web
flutter run -d windows    # Windows (or macos / linux)
flutter run               # Connected Android or iOS device / emulator
```

To rename the app, change `name:` in `pubspec.yaml`, the package imports in
`lib/` and `test/`, and the display name in the generated platform folders.

## What is included

```text
lib/
├── main.dart
├── app/                  # MaterialApp, routing and the navigation shell
├── core/
│   ├── constants/        # App-wide constants
│   ├── interaction/      # TactileSurface and organic input feedback
│   ├── layout/           # AdaptiveScaffold, ListDetailLayout, SupportingPaneLayout
│   ├── motion/           # Context-aware motion (ContextualSwitcher, SmoothExpandable)
│   ├── platform/         # Platform detection, scroll behaviour
│   ├── responsive/       # Window size classes and builders
│   ├── theme/            # Material 3 theme, spacing, radii, motion tokens
│   └── widgets/          # Reusable responsive widgets (FeedbackStateView, ...)
└── features/
    ├── home/             # Sample dashboard
    ├── components/       # Material 3 component showcase
    └── settings/         # Theme mode and appearance settings
```

Highlights:

- **Material 3 theme** with light and dark schemes generated from one seed
  colour (`lib/core/theme/app_theme.dart`).
- **Window size classes** following the Material 3 adaptive breakpoints
  (`lib/core/responsive/breakpoints.dart`).
- **Adaptive navigation**: bottom navigation bar, navigation rail and extended
  rail chosen automatically (`lib/core/layout/adaptive_scaffold.dart`).
- **Reusable responsive widgets** for page content width and card grids.
- **Strict analysis** including mandatory doc comments
  (`analysis_options.yaml`).
